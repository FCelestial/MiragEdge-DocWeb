# 死亡回程

每次死亡后，系统自动记录死亡位置，你可通过 `/back` 返回死亡点。

## 死亡记录

死亡时系统会记录死亡位置（世界 + 坐标），并覆盖上一次的记录。排除了 `pvp` 和 `zc` 世界的死亡不会记录，这些世界也禁用所有死亡回程功能。

死亡后 Java 版玩家会收到一条带坐标的可点击消息，点击即可返回。基岩版玩家在重生约 **2 秒** 后弹出「返回死亡点 / 取消」表单，表单 30 秒后自动关闭；若未弹出，手动输入 `/back` 即可。

## /back 返回死亡点

```bash
/back
```

**权限**：`feback.use`（默认所有人）

**冷却**：5 秒（权限 `feback.bypass.cooldown` 可跳过）

**返回费用**：按今日累计死亡次数阶梯收费，每天 0 点刷新次数。

| 今日死亡次数 | 费用 |
| :---: | :---: |
| ≤ 30 次 | 免费 |
| 31 ~ 40 | 100 灵叶 |
| 41 ~ 50 | 200 灵叶 |
| 51 ~ 60 | 300 灵叶 |
| 61 ~ 70 | 400 灵叶 |
| 71 ~ 80 | 500 灵叶 |
| 81 ~ 90 | 600 灵叶 |
| 91 ~ 100 | 700 灵叶 |
| 101 ~ 110 | 800 灵叶 |
| 111+ | 1200 灵叶 |

权限 `feback.free` 可跳过所有费用。

**返回后负面效果**：饥饿值 -2、失明 3 秒、缓慢 4 秒。

**跨世界返回**：允许跨世界返回（无需额外权限），死亡点世界已删除则无法返回。

## 阶梯死亡惩罚

每次死亡会根据当日累计死亡次数扣除灵叶，以发光的金粒「遗失的灵叶」掉落在死亡点。

| 当日死亡次数 | 阶梯 | 扣除灵叶 |
| :---: | :---: | :---: |
| 1 ~ 3 | 免罚 | 0 |
| 4 ~ 6 | 轻度 | 100 ~ 250 |
| 7 ~ 10 | 中度 | 250 ~ 500 |
| 11 ~ 15 | 重度 | 500 ~ 800 |
| 16 ~ 20 | 严重 | 800 ~ 1200 |
| 21+ | 最高 | 1200 ~ 1500 |

> 每日 0 点重置次数，新的一天从第一次开始。

## 遗失的灵叶

扣除的灵叶化为 **1 颗** 发光的金粒掉落死亡点，名为「**遗失的灵叶 ×N**」（N = 实际扣除灵叶数）。

- **存在时间**：6 分钟，超时自动消失
- **不可合并**：每颗金粒是独立物品，拾取后一次性转账
- **生物不拾取**：僵尸、猪灵等不会捡走

**拾取规则**：

| 情况 | 拾取结果 |
|------|----------|
| 自己走回死亡点 | 正常拾取，灵叶回到账户 |
| 使用 `/back` 后 | 自己不能拾取（防套利），他人可拾 |
| 他人路过捡起 | 灵叶转入拾取者账户，原主收到通知 |

## 自杀指令

```bash
/febsuicide
```

**权限**：`feback.suicide`（默认不开放给玩家）

通过自杀死亡不计入当日死亡次数、不扣费、不掉金粒，但死亡点仍会记录，可用 `/back` 返回。控制台可通过 `/febsuicide <玩家名>` 指定目标玩家自杀。

## 管理员指令

```bash
/feb reload          # 重载配置
```
